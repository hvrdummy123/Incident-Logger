# Demo walkthrough (spoiler-free)

1. `docker compose up -d --build` (or `traceiq serve` + `cd web && npm run dev`).
2. Sign in with a seeded local user.
3. On an empty incident list, choose **Load a demo incident** (or pick demo 1/2/3).
4. Open the incident → **Run investigation (mock)**.
5. Watch steps; open the report; click citation chips; submit feedback.

BYO path: **Bring your own logs** with `samples/formats/*.log`.

See `demo/answers/` for ground truth of each demo bundle. Do not read before trying the demos yourself.
