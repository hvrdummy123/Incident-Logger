# Contributing

This is primarily a portfolio / single-maintainer project. If you open a PR:

1. Keep changes small and explain the *why*.
2. Run `make lint` and `make test` before pushing.
3. Do not commit secrets, real customer logs, or Loghub datasets.
4. Prefer extending tests over adding abstraction layers.

Commit messages: lowercase, specific, no emoji. Example: `drain: stop merging templates with different token counts`.
